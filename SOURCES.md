# MiraCosta CS 111 Public-Source Inventory

Last checked: July 27, 2026

## Method and boundary

The search covered the open web, GitHub organization and user repositories, current public GitHub Classroom templates, indexed historical course documents, and student-created study sets. Searches combined `MiraCosta`, `CS 111`, `CS111`, `Java`, Topic and Lab numbers, instructor account names, `quiz`, `exam`, `midterm`, `final`, `review`, and distinctive historical question text.

Only public pages were inspected. No current locked Canvas quiz or final, paywalled page, private repository, or student answer repository was used as an answer source. The practice bank contains newly written multiple-choice questions; it does not reproduce a protected test bank.

## Excluded or non-evidence sources

- Generic courses named CS 111 from other colleges and universities
- Misclassified CourseHero documents for unrelated CS courses
- A Studocu course page with unrelated uploads and no usable CS 111 quiz bank
- Current locked Canvas items
- Commercial or paywalled content beyond its public preview
- Student solutions and copied answer repositories

## Search conclusion

No public, current MiraCosta CS 111 multiple-choice final bank was found. The most complete defensible public record is the official catalog plus the instructor-managed practice and Lab 03–19 repository sequence, corroborated by the Spring 2026 classroom templates. The dedicated 90-question bank therefore follows that sequence and uses the historical quiz/review previews only for secondary emphasis.
