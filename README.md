# CS 111 Final Lab

Interactive final-exam study site for MiraCosta CS 111, Summer 2026.

## Features

- 15-topic bilingual knowledge map
- 65-question original mock final
- 100-minute timed mode and 10-question quick practice
- Immediate answer feedback and explanations
- Local mistake notebook and topic-level diagnostics
- Responsive, keyboard-accessible static site

The mock questions are original study material based on visible course content. The site does not contain locked exam questions or protected quiz answers.
