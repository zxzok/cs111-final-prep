# CS 111 Final Lab

Interactive final-exam study site for MiraCosta CS 111, Summer 2026.

## Features

- 15-topic English knowledge map
- 140-question all-multiple-choice practice bank
- Separate 90-question MiraCosta public-source practice bank
- Source links and confidence labels for every MiraCosta-specific question
- Random 15-, 30-, and custom-length MiraCosta practice sessions
- Coverage- and difficulty-balanced random 65-question exams
- 100-minute timed mode and balanced 10-question quick practice
- Immediate answer feedback and explanations
- Local mistake notebook and topic-level diagnostics
- Responsive, keyboard-accessible static site

The mock questions are original or substantially adapted study material based on visible course content and public college-level Java references. The site does not contain locked exam questions, protected quiz answers, or copied commercial test-bank content.

The dedicated MiraCosta bank is based on the public course catalog, instructor-managed practice and lab repositories, Spring 2026 GitHub Classroom templates, and limited historical quiz/review previews. See [SOURCES.md](SOURCES.md) for the source inventory and evidence boundary.
